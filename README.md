# Customer Service Management — Power Platform & Dynamics 365

Projeto de demonstração e portfólio profissional utilizando **Fusion Development** para a **Microsoft Power Platform**.

## 🛠️ Tecnologias Utilizadas
- **Microsoft Dataverse**: Modelagem de dados relacional e controle de regras de negócio.
- **Power Apps (Model-Driven App)**: Interface de gerenciamento de atendimento a clientes.
- **Power Automate**: Automação de processos e notificações.
- **C# .NET Plugins**: Lógica de negócio server-side estendendo as capacidades do Dataverse.
- **Power Platform CLI (`pac`)**: Gerenciamento de soluções, autenticação e deploy via linha de comando.
- **Git & GitHub**: Controle de versão e ciclo de vida de desenvolvimento (ALM).

## 📂 Estrutura do Repositório
- `solutions/`: Pacote de soluções desempacotadas (Dataverse Solutions).
- `src/plugins/`: Código-fonte C# dos plugins customizados.
- `docs/`: Documentação e diagramas do projeto.
